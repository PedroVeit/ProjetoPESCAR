# Pasta de dados

As planilhas de candidatos e o Controle NIGE **não são versionados** neste
repositório, pois contêm dados pessoais sensíveis (renda, raça, bairro etc.).

Para rodar as análises localmente, copie as planilhas (.xlsx / .xlsm) para
esta pasta. O .gitignore garante que elas não sejam enviadas ao GitHub.
